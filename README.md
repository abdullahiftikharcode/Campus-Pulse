# Campus-Pulse
Campus Pulse is a robust club and society management app crafted using Java and XML, offering intuitive functionalities for seamless organization and communication within campus communities.
Users begin by signing up with unique usernames and emails, ensuring secure access through a dedicated login page with auto-login capability for subsequent sessions, enhancing user convenience.

The app employs stringent validation and encryption protocols for usernames, emails, and passwords, prioritizing user security. A unique club code system, akin to Google Classroom, facilitates easy club joining and sharing, enhancing accessibility and user engagement.

Administrators wield powerful tools for managing clubs, including the creation and deletion of announcements and detailed event scheduling. They oversee member lists, promoting admins, managing roles, and maintaining club integrity.

Members enjoy streamlined access to club announcements, events, and notifications, tapping into detailed information directly from their profiles. They can easily leave clubs when needed, fostering flexibility and user autonomy.

The app also features a comprehensive profile management section where users can view their joined club count and update profile details securely. An informative About section includes links to app owner profiles on LinkedIn and Instagram, fostering transparency and community engagement.

Powered by a Gemini-driven chatbot, Campus Pulse ensures users receive prompt assistance with app-related queries, enhancing usability and support accessibility.

With robust ownership management logic, clubs maintain continuity even if admins change, ensuring smooth transitions and preserving community continuity. Campus Pulse is designed to empower campus communities with efficient club management tools while prioritizing user security and ease of use.
